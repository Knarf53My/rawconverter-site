Common questions

My camera’s RAW files won’t open.
RawConverter uses the RAW engine built into macOS, so it supports the cameras on Apple’s list. Support for brand-new camera models can arrive a few months after release, through a macOS update.

Where are my edits saved?
In a small .rawedit file next to each photo (for example P9140004.rawedit beside P9140004.ORF), and in the app’s own library. Your original RAW files are never changed.

A yellow warning triangle appears next to a photo.
macOS hasn’t given RawConverter permission to save in that photo’s folder yet. Right-click the photo, choose “Allow Saving Edits Next to Photo…” and confirm the folder.

How do I apply the same edits to many photos?
Edit one photo and choose Edit › Copy Settings (⇧⌘C). Select the other photos, choose Edit › Paste Settings… (⇧⌘V) and tick the groups you want to paste.
